# Tirta Jaya — Emergency Logistics Case

Fictional exercise for testing route algorithms and greedy/optimization strategies during flood-related delivery disruptions.

## Network
Import `examples/TirtaJaya_Jaringan_Jalan.csv` in Route Intelligence. File format: `source,target,weight`.

## Scope
The dataset is simulated. Weights are abstract costs, not live minutes or kilometers. The current UI solves shortest-path routing; load selection and activity scheduling are separate examples, not jointly optimized by the app.
