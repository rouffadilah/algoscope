# AlgoScope — Algorithm Intelligence Platform

AlgoScope is a browser-based algorithm exploration and benchmarking dashboard. It helps users run selected classic algorithms, visualize results, compare algorithm behavior, and experiment with weighted graph routing.

## Quick start

Open `index.html` in a modern browser. The core dashboard is a static front-end and does not require an install step.

## Contents

- `index.html` — main interactive dashboard
- `assets/brand-as.svg` — AS monogram brand mark
- `docs/ROADMAP.md` — product roadmap and planned capabilities
- `examples/` — sample network data and emergency-logistics case study files

## Current scope

The application includes an algorithm explorer and graph-routing experiments. Runtime and benchmark values are measured in the browser and can vary by device. The sample graph data is simulated, not real-time traffic data.

GitHub Pages can serve this static site. In the repository settings, open **Pages**, select deployment from the `main` branch and the root folder, then save.
