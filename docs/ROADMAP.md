# AlgoScope Roadmap

## Current prototype
- Browser-based algorithm explorer and graph-routing dashboard
- Simulated data and client-side runtime measurement
- CSV export and sample network import

## Next milestones
1. Improve algorithm correctness tests and reusable test cases.
2. Add visual step-by-step traces and support for more fundamental and advanced algorithms.
3. Add experiment workspaces, reproducible configurations, and report exports.
4. Introduce authentication, persistent storage, and team projects through a secure backend.
5. Offer an API and CI integration for repeatable algorithm performance checks.
6. Prepare production operations: security review, observability, backups, accessibility, and support processes.

## Production caveat
Login, cloud persistence, live traffic feeds, team collaboration, billing, and API integrations are future milestones, not active features in the static prototype.
